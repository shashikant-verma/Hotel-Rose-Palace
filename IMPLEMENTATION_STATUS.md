The CSS is already available via `@vite('resources/css/app.css')` in the layout. Pages automatically get:
- Proper background colors (#EDE4D8)
- Typography styling (Playfair + Lato)
- Card styling with champagne backgrounds
- Button styling with burgundy primary color
- Footer with burgundy background
- Responsive design

