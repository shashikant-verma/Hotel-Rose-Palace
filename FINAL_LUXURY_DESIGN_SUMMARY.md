## 🎓 FOR FUTURE DEVELOPERS

### Design System Usage
When adding new features or pages:
1. **Use CSS Variables**: `var(--color-burgundy-rose)`, `var(--font-heading)`
2. **Follow Color Palette**: Never use #FFFFFF, #000000, or hardcoded colors
3. **Responsive Design**: Use mobile-first approach with media queries
4. **Typography**: Use Playfair Display for headings, Plus Jakarta Sans for UI
5. **Spacing**: Use 8px multiples (8, 16, 24, 32, 48px)
6. **Borders**: Use #D8CBB8 or rgba equivalents from palette
7. **Buttons**: Apply btn-primary, btn-secondary classes
8. **Forms**: Use form-control, form-label classes
9. **Testing**: Test on 375px, 768px, 1024px, and 1920px viewports

### Common CSS Patterns
```css
/* Colors */
color: var(--color-charcoal-deep);
background: var(--color-champagne);
border: 1px solid var(--color-border-subtle);

/* Typography */
font-family: var(--font-heading);
font-size: clamp(24px, 4vw, 36px);

/* Spacing */
padding: 24px;
margin-bottom: 32px;
gap: 16px;

/* Transitions */
transition: all 0.3s ease;

/* Hover Effects */
transform: translateY(-4px);
box-shadow: 0 8px 20px rgba(46, 31, 34, 0.12);
```
