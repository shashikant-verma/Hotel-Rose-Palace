## 🛠️ MANAGING IMAGES AFTER UPLOAD

### Edit Image
```
Admin > Gallery
    ↓
Click image thumbnail
    ↓
Click Edit button (pencil icon)
    ↓
Edit title, category, alt text, order
    ↓
Click Save
    ↓
Changes applied ✓
```

### Hide Image
```
Click image thumbnail
    ↓
Click Eye icon
    ↓
Image becomes inactive
    ↓
Still in database, not visible on website
```

### Delete Image
```
Click image thumbnail
    ↓
Click Delete button (trash icon)
    ↓
Confirm deletion
    ↓
Image permanently removed
```

### Reorder Images
```
Edit image
    ↓
Change "display_order" number
    ↓
Lower number = appears first
    ↓
Save changes
```
